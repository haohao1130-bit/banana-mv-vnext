# Continuous-film photography and compact controls

New author requests reuse the installed official Ref2VA guide (cfg.guides.ref).
The upstream 9B call now writes filming_prompt and ongoing_filming_prompt for
each timed view. These are finished native shot paragraphs, not plot summaries.
The compiler places them under the six existing H3 headers and local Shot labels;
it never calls a per-window writer. Mid-beat entries use only ongoing prose.
Review sees the actual prose; repairs receive the same photography commission
and installed guide. SRT remains optional and audio reuse remains unchanged.

Legacy saved masters without these fields retain their existing compiler. Start
a NEW recipe after updating to exercise the new authoring contract. Prompting
cannot guarantee photographic quality; a real 9B recipe review is still required.
No word-count, shot-count or camera-technique quota is enforced.

The form folds director/music/identity settings, render acceleration settings and
retry settings into separate closed details panels. Values, IDs and submission
behavior are unchanged. Lyrics/SRT and voice panels remain separately accessible.

Reference: https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md
The guide specifies six sections, natural-language camera movement, detailed
composition/action rather than synopsis, and timestamped shots (sections 1, 5).
