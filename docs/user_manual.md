# Banana MV 操作手冊

## 開爐

在 Colab 依序執行①安裝、②下載模型、③啟動，再點輸出的 MV 介面。第一次可用短音訊確認環境；測試事件、表演與剪輯時，再用約 10–15 秒的片段。既有任務用保存的模型、尺寸與分段設定；要換整體設定，建立新任務。

依欄位順序上傳角色／場景圖，控制詞用 `@圖片1`、`@圖片2` 對應。圖片編號固定，不因角色退場遞補；同一人的多角度不代表不同角色。人物圖用來認人，不鎖住表情、眼睛、姿勢或情緒。沒有參考圖的配角可用文字描述，不要引用不存在的圖片。

上傳原歌曲；可另提供同起點、同長度的隔離人聲供對嘴驅動，最後完整成片仍使用原歌曲。音訊負責實際聲線與節奏。9B 沒有直接聽音訊，音樂分析只有強弱／起音／停頓等量測，不能自動辨識男女歌手或副歌。

## 寫故事、選拍法

寫清故事主軸、角色分工、場景關係、必要事件與結果。要雙線交錯，說明各線如何推進、場地是否隔離。不要靠圖片排列或歌詞引用句猜誰在唱。

- 自動導演：按內容選擇拍攝方向；也可指定演唱、武打、舞蹈等模式。
- 自然：克制表演與細微攝影；高動態：較強鏡位、運動與剪輯；電影級爆發：更強的尺度、光影、表演及節奏反差。強度不是單純增加顆粒或特效。
- 導演主導／全曲事件規劃：開啟時，9B 可沿主軸合理擴寫；關閉時以原事件安排為主。兩者都保留身分、聲部及明確限制。
- 動態切鏡：允許場景交錯與同場景內多個鏡頭；生成段長不等於每鏡鏡長，不設每鏡至少 3–5 秒。
- 獨立分段：各段使用原參考圖；末幀接續：使用上一段實際末幀，並保留原角色圖。接續模式的圖片上限較少。

歌詞用來理解內容；SRT 提供與上傳音檔起點一致的時間參考。請在文字中明確標示聲部；9B 不會因一句「你說收到」就真的聽見女聲。SRT 不自動燒成字幕，也不應被轉成新增台詞。不要把另一個剪輯版本的 SRT 直接貼給不同長度的音訊。

## 看大綱、提示詞與毛片

上游看全片，分配各段的自足拍攝委託。下游只取得當段角色／場景、接手狀態、事件、當段結束狀態與必要規則，自主設計表演和攝影，不收全劇共用設定或未來結局。

生成紀錄可看完整大綱、每段實際送入 H3 的提示詞及 Seed。「丹藥檢查」顯示已完成的無聲毛片，能邊生成邊播放及勾記；毛片沒有聲音是正常流程，並不代表 H3 沒有收到對嘴音訊。最後合成才混入一次原曲。

要更新程式，請載入新版 Colab 程式。已保存提示詞／回爐不會自動套用新導演政策；舊大綱缺少當段委託時，需建立新任務重新分配，不能把整首故事補送下游。

## 每顆丹藥的局部修改

每段卡片有「局部修改建議」欄位，以該段目前採用版為基礎：

| 填法 | 回爐行為 |
| --- | --- |
| 留空 | 原提示詞不變，只換未用過的 Seed。 |
| 填寫修改建議 | 9B 收到這段原提示詞、修改意見、原參考圖與局部時間資訊，產生完整修正版，再換 Seed 重拍。 |

例如「只增加按鍵操作特寫，其餘事件保留」「主角表情隨動作逐步升高」「修正這段的聲部分配，其他畫面不改」。修改針對這段，不重新生成全曲大綱，也不把其他段落、共用設定或未來劇情送給修稿器。每段最多 3000 字；需要已下載本地 9B 與原生指南。

選好要回爐的段落，待任務完成或停止後按「將所選丹藥回爐重煉」。每段可填不同意見，未勾選的段落不套用。輸入草稿會在同一瀏覽器保留，狀態更新不重建播放器或清掉文字。預覽舊版不會改變基底；要以舊版回爐，先按「採用此丹」。

每個回爐版保存修改意見、實際提示詞、workflow、Seed 與毛片。有局部改寫時另保存修稿輸入和原始回應。採用新版或切回初煉版時，當段提示詞也跟著切換；之後留空回爐會使用目前採用版的提示詞。

## 完整作品也保留每一版

回爐是同一首作品的第二、第三版成片，不是重新作曲或建立另一個故事。回爐只保存候選；逐段選用版本，再確認凝丹／合成才產生新版；其餘段落不重新採樣。局部修稿、採樣或合成失敗會保留原本採用版；已完成候選仍可在段落版本選單查看。

每次成功合成都另存完整版本。介面的「完整作品版本」可分別下載第 1、2、3 版；「下載完整 MV」與 `final.mp4` 指向目前版本。切回某個舊毛片並合成，也會成為新的完整作品版本，既有成片不刪除。

對已有舊成片的專案，第一次回爐會先保存原 `final.mp4` 為第 1 版，再存第 2 版。沒有完整成片的部分任務只保存候選毛片，不會假造一支完整作品。

末幀接續時，相鄰且同批回爐的段落使用新版前段末幀；未選後段不自動重跑，請看片檢查接點。停止會等目前候選完成，不自動採用未完成批次。

## 去哪裡找最後作品

正式版③勾選 Drive 保存時，主要位置是：

```text
MyDrive/BananaMV/banana_mv/工作編號/final.mp4
MyDrive/BananaMV/banana_mv/工作編號/final_v001.mp4
MyDrive/BananaMV/banana_mv/工作編號/final_v002.mp4
```

`final.mp4` 是目前版本，`final_vNNN.mp4` 是保留的完整歷史成片。各段回爐素材在同一工作資料夾的 同目錄的 `00_raw_v2.mp4`、`00_part_v2.mp4`、`00_prompt_v2.txt`、`00_workflow_v2.json`（依段號與版本成組保存）。請以介面顯示的實際「目前完整作品」路徑為準，**不用到 videos 才能找到成品**。

`videos` 是另外嘗試另存的副本，成功時檔名也帶版本號；副本失敗不影響工作資料夾的成片或下載。未勾 Drive 時，資料根目錄為 `/content/banana_mv_data`，Colab 回收後可能消失。舊 T8 攝影政策測試入口已停用；請使用本倉庫 main 的正式筆記本。

## 續跑與結束

掛載原本 Drive，開啟已保存專案再續跑，不需重傳素材。續跑沿用已完成影片與已存稿；回爐只針對勾選段落。不要讓兩個執行階段同時修改同一個專案。

前端「目前這段完成後停止」會保留完成段落；Colab 的手動關閉 ComfyUI 會立即中止服務。關閉網頁或 ComfyUI 不等於釋放 GPU，結束運算需在 Colab 中斷並刪除執行階段。

局部修改與成片版本已做離線流程／介面測試；實際 9B 修稿服從程度、H3 表演品質及手機 Colab 操作仍以實測為準。



## 先搓丹方，再開爐

建立 MV 現在有兩個按鈕：

- **直接煉丹**：沿用原流程，9B 分配各段故事後接著生成影片。
- **先搓丹方**：先做音樂分析（若有開啟）與 9B 上游故事分配，顯示各段時間、模式與完整事件，停在「丹方審閱・尚未開爐」。此階段不進行逐段攝影改寫或 H3 影片採樣。

檢查後按 **丹方無誤，開爐**，沿用同一份故事、圖片、歌曲、Seed 與原設定，才進入當段攝影改寫與影片生成，不重新規劃故事。這版丹方為唯讀審閱；若要更換故事，修改原始控制詞後建立新任務。

先搓丹方需要開啟本地提示詞改寫；「自動導演」關閉時仍可審閱忠實模式的故事分配。等待確認的專案會保存，可從專案列表重新開啟；重新啟動服務不會替它開爐。保存是否跨 Colab 執行階段取決於是否啟用 Drive 保存。

開爐確認綁定當下丹方版本；重複確認、過期畫面或保存內容不一致會被拒絕。規劃失敗可續跑，尚未確認的任務仍會先回到丹方審閱。開爐後的錯誤可沿用原續跑流程，已確認的故事不重抽。

更新後需重新載入後端與前端。既有專案和直接煉丹的行為維持原樣。本功能的離線檢查不代表 9B／H3 真實生成品質已驗證。
