歌詞與 SRT 參考（選填）

兩欄可分開使用。歌詞提供全曲語意，SRT 依原歌曲起點的時間碼，對齊各段內容；跨段歌詞會同時提供給重疊的段落。需開啟9B才用於導演與改寫，不會自動燒字幕或改寫原曲。沒有填寫的時間不代表靜音。

人聲與進階設定

人聲須與原曲同起點、同長度，保留靜音。未提供時以完整混音驅動畫面；目前不自動分離人聲。

另行製作的純音效／配音軌，請勿混入歌曲。與原曲同起點、同長度，空白處保留靜音。有聲部分最多佔全曲 25%，每次最多 3 秒；合成時自動壓低音效音量、保留原曲主體。目前不自動生成音效或配音。

第一次生成 MV
  1. 在 Colab 依序執行①安裝、②下載模型、③啟動，開啟前端。
  2. 依控制詞編號逐格選取參考圖，再上傳原歌曲。第一次先用 5 秒音訊，確認模型、節點與對嘴。
  3. 選擇比例、導演模式與動作強度，選填「想拍什麼」，按開爐煉製 MV。
  4. 生成紀錄會更新各段狀態；全部完成後可播放、下載完整 MV。

    
多張圖片與角色怎麼分工？
圖片欄位預設全部顯示，每格只上傳一張，編號固定為 @圖片1、@圖片2 等。依控制詞把角色、角度或場景放到對應欄位；清除一格不會替其他圖片重新編號。請從圖片1起填入，需要時補齊中間的空格，末尾可留空。
@圖片1 是主唱，在演唱會表演。
@圖片2 是拳擊選手，在另一個場地對戰。
兩條畫面依音樂交錯；拳擊選手不演唱。
對手與裁判由文字描述生成。
配角可以沒有參考圖；不要把第三位角色寫成不存在的「圖片3」。同一人的多個角度，也不代表多個人。獨立分段最多9張；末幀接續最多8張。

    
導演、全曲規劃與動作強度
自動導演：依你的內容選擇適合的模式；也可指定演唱、武打、舞蹈等方向。動作強度：控制動作與鏡頭的引導強度，越高不一定越清楚，先用自然或高動態試拍。
本地 9B 優化：把內容改寫成生成提示詞。導演主導・全曲事件規劃：需開啟9B，允許依音樂重排、展開或濃縮故事；仍保留圖片身分、演唱分工與明確不可改的限制。未勾選時，以原控制詞的事件安排為主。
音樂分析：提供強弱、起音與停頓。9B 不直接接收音訊，不會自動辨識男女聲線、歌詞或副歌；節奏數值是估計。原曲是影片的連續音樂主軸，對嘴效果仍需看片確認。

    
分段模式與人物清晰度
獨立分段：每段使用同一組參考圖，適合 MV 換鏡。末幀接續：以上一段末幀作為下一段首幀，並保留所選圖片參考；不等於多幀動作上下文。
每段選10或15秒，尾段按剩餘音訊生成；歌曲最多五分鐘。主唱用半身或更近的鏡頭較利於保留臉部與嘴部細節；高速動作、遠景與密集切鏡需實測調整。

    
煉丹動畫、進度與改寫提示詞
投藥：上傳、音樂分析、分鏡規劃或提示詞改寫。旺火：影片採樣。凝丹：片段與原曲合成。出丹：完成下載。
進度條計算已完成段落，不是 GPU 每一步的採樣百分比；本段生成時停在同一個數字是正常的，請搭配目前階段查看。
展開「查看改寫後提示詞」可選擇段落、閱讀和複製最後實際送入 H3 的版本，不會改動你原本填的控制詞。

    
生成失敗、斷線與續跑
先看紀錄中的錯誤與發生階段。環境或模型問題需先修復；之後開啟原專案，按續跑未完成段落，沿用保存的設定與素材，保留已完成的片段。
前端暫時斷線會重新查詢，不代表 GPU 已停止。Colab 執行階段仍可能中斷或回收；需要跨次續跑，請在③勾選 Drive 保存。不要讓兩個執行階段同時續跑同一專案。
新版當段改寫交稿失敗時使用設定的有限次重試；仍失敗就保留錯誤與已完成段落，不會把整首故事補進當段。原控制詞寫錯圖片編號時，仍需自行修正。

    
上游與下游怎麼交接？
上游理解全片後，為每段分配角色、場景、接手狀態、事件與當段結束狀態。下游只收到這份當段委託，自主設計表演、運鏡與蒙太奇，同時收到角色圖片綁定、固定場景與演唱分工；不收未來劇情或未輪到當段的結局。新任務不啟用舊跨段狀態帳本。
參考圖只辨識角色與指定外觀，不固定表情、眼睛或姿勢。歌詞理解不等於實際聲部辨識；請提供明確聲部分配。舊計畫缺少新版當段委託時，需建立新任務重生大綱；已保存影片與提示詞不會重寫。
歌詞與 SRT 參考怎麼用？
展開表單的「歌詞與 SRT 參考」，可分別貼全曲歌詞，以及匯入或貼入 UTF-8 SRT。兩欄都可留空，也可只填一欄。開啟9B後，歌詞供全曲語意參考，SRT 按時間對照事件；跨段歌詞會提供給每個重疊段落。
SRT 時間碼需相對目前上傳的歌曲起點，格式為 HH:MM:SS,mmm。若歌曲已剪短，SRT 也要同步平移。參考內容不會直接燒成字幕，也不會改寫原曲；無字幕的區間不代表靜音。
局部修改與完整成片版本
在每段「局部修改建議」填這段要改的內容，再勾選回爐；9B 只看該段原稿、修改意見與必要參考，不重排全曲。留空只換 Seed。預覽舊版不會改變基底，需要時先「採用此丹」。
全部成功後另存第二、第三版完整 MV，第一版仍保留；若修稿、生成或合成失敗，原採用版不變。回爐與採用舊毛片都會保存新的完整成片版本；局部修改需已下載本地 9B。
保存、Seed 與關閉 ComfyUI
③勾選保存到 Drive 時，專案在你的 MyDrive/BananaMV；未勾選則在本次 Colab 執行階段，回收後可能消失。再次啟動時掛載同一個 Drive，再開啟原專案。完整作品的主要位置是 MyDrive/BananaMV/banana_mv/工作編號/final.mp4。每次成功合成另存 final_v001.mp4、final_v002.mp4 等歷史成片，可在「完整作品版本」下載。videos 僅為另存副本。
「人聲與進階設定」裡可填 Seed，留空隨機；本次使用值會顯示在生成紀錄。比較效果時也需保持其他設定一致，固定 Seed 不保證跨環境結果完全相同。
前端的停止按鈕會等待目前段落完成。Colab 底部的手動關閉 ComfyUI按鈕則會立即停止 ComfyUI，可能中斷當前段落；「全部執行」只會顯示該按鈕。重跑③可以再啟動。
停止 ComfyUI 不會解除 Colab 的 GPU 配置。結束 GPU 使用請在 Colab 中斷並刪除執行階段。
